# Importa Colaborador 1.0

Arquivos desta versão:

- `img/Importa Colaborador 1.0.csv`: planilha para preencher os colaboradores.
- `DB/Importa Colaborador 1.0.sql`: arquivo para importar no phpMyAdmin.

Abra a planilha no Excel, preencha os dados e arraste a fórmula da coluna `SCRIPT_SQL_PHP_MYADMIN` para cada linha. Copie o conteúdo gerado, cole no arquivo SQL abaixo do comentário indicado e importe no phpMyAdmin.
