# Versionamento do Primorely

Antes de concluir qualquer mudança solicitada pelo usuário neste repositório:

1. Classifique a entrega conforme versionamento semântico `MAJOR.MINOR.PATCH`.
2. Atualize `VERSOES.md` e `versoes.html` com a versão, data e resumo objetivo da mudança.
3. Atualize a versão exibida em Configurações › Sobre.
4. Não inclua segredos, tokens, dados pessoais, endpoints privados ou instruções de autenticação nos registros públicos de versão.

Use PATCH para correções, ajustes visuais, regras compatíveis e segurança; MINOR para funcionalidades novas compatíveis; MAJOR para mudanças incompatíveis.
